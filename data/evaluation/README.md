# 초기 합성 실험 v1

`cases.tsv`는 이 프로젝트를 위해 작성한 한국어 가상 문장 96개다. 실제 피해 대화나 외부 데이터셋을 복사하지 않았다. 개인정보와 실제 링크를 넣지 않았다. 학습 36개(각 상태 12개), 개발 40개, 보류 20개로 고정했다. 평가 60개는 위험 24개(유형별 6개), 정상·예방 24개, 판단 곤란 12개다.

각 행은 독립 작성한 단일 메시지이며 ID는 헤더를 제외한 행 번호다. 동일 문장 정규화 중복은 로더가 거부한다. 단순히 행이 다르다고 독립성이 입증되지는 않는다. 학습·평가에 유사 표현과 같은 행위 개념이 있고 작성자가 같아서 수치가 낙관적일 수 있다. 보류 문구도 구현자가 작성했으므로 외부의 블라인드 평가가 아니다. 다화자 대화 의미 평가, 원문 그룹의 유사성 검토, 2인 라벨 검토와 사례별 허용 인용·판단 이유 주석은 아직 미완료다.

위험 행은 `tag`에 해당하는 실제 요구·주장을 포함하도록 작성했다. 정상은 정상 거래·예방·부정·거절 맥락, 판단 곤란은 주체·대상·목적이 빠진 요청이다. 상세 판정 기준은 `docs/decision-criteria.md`에 있다. 태그는 분류기 학습 입력으로 쓰지 않는다. 공식 자료 검색 코퍼스 및 시연 예시와 학습 데이터는 별개다.

문자 TF-IDF(2~5그램), 로지스틱 회귀 C=1, balanced, seed=42를 첫 실행 전에 고정했다. 개발 결과에 맞춰 튜닝하지 않았다. 보류를 열려면 CLI에 `--final`이 필요하다. 보류 평가 후 설정을 고치면 새 보류 자료로 다시 평가해야 한다.

실행 방법은 루트 README를 참고한다. 생성 모델과 상세 평가 결과는 git에서 제외한 `artifacts/`에 저장한다. 이 데이터는 초기 회귀·작동 실험용이며 한국어 사기 탐지의 실사용 정확도를 입증하지 않는다.

`regression.json`은 실제 LLM의 문맥 분석을 집중 확인하는 합성 사례 14건이다. 5개 핵심 태그, 예방·부정·과거 인용 거절, 정상 정산·공식 앱 안내, 프롬프트 공격, 띄어쓰기 변형, 맥락 부족, 이모지·반복 인용과 다화자 대화를 포함한다. 이 묶음은 학습·개발·보류 96건과 별개이며, 별도 회귀 검사로만 보고한다. 각 사례는 기대 상태·태그와 판단 이유를 포함한다. 회귀 결과를 보고 프롬프트를 고친다면 수정 전후 기록을 남겨야 한다.

`cases.tsv`의 첫 줄은 파일 용도 주석이며 로더가 건너뛴다. 주석 추가 전후 학습 데이터 SHA256이 같은지 회귀 테스트로 확인한다. JSON은 첫 줄 주석을 허용하지 않아 원래 형식을 유지한다.
