# 검토된 공식 자료

2026-11-08에 공식 웹 본문에서 확인한 예방 자료 5개를 연결한다. 서버는 이 파일들만 검색하며 사용자 입력의 URL에 접속하지 않는다. `sources.json`의 출처와 `chunks.jsonl`의 인용을 함께 관리한다.

검색 조각은 문서별 25단어 미만의 짧은 원문 인용이다. 공백이 어색한 “입 금”, “인출 하려면” 등도 확인한 본문 표시를 유지했다. 법적 구제·신고 효과·등록 상태는 자동 판단하지 않는다. 다섯 자료가 모든 유형·모든 요구를 포괄한다는 뜻은 아니다.

FSC-002의 텍스트에는 공공누리 제4유형이 표시되어 있다. 원문·카드뉴스를 가공해 배포하지 않고 비상업적 시연의 분석 설명에 필요한 짧은 인용과 링크만 제공한다. 나머지 자료에도 무제한 재사용 허가를 주장하지 않는다. 상세 이용 범위는 각 `usage_notes`에 기록했다. 상업적 공개 배포로 범위가 바뀌면 이용 조건을 다시 확인한다.

화면의 LLM 설명은 인용 원문과 별도로 표시하는 분석 해석이다. 출처의 공식 문구로 취급하지 않는다. 검색·출처 ID 검증은 원문 확인과 다른 검사이며, 실제 관련성은 사람이 추가 검토해야 한다.
