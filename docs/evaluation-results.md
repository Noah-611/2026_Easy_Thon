# 초기 CPU 비교 기록 — 2026-11-09

학습 36건, 개발 40건, 보류 20건의 합성 자료만 사용했다. TF-IDF/로지스틱 회귀 설정과 규칙은 첫 개발 평가 이전에 고정했고, 결과에 따라 수정하지 않았다. 지식 검색 코퍼스는 학습에 쓰지 않았다.

분류기는 정상 오탐이 개발·보류 합계 5/24건으로 계획의 초기 목표 2/24건 이하에 미달한다. 위험 탐지는 19/24건으로 목표 20/24건 이상에 미달한다. 보류 결과가 개발 결과보다 좋아도 데이터가 작아 일반화 성능 향상으로 해석할 수 없다. 규칙도 판단 곤란 상태를 놓치므로 단독 서비스 판정으로 쓰지 않는다.

Python 3.12.13 / scikit-learn 1.9.1. 학습 SHA256: `a51f16a56243b2800cefbf71a5c803b1aaf99380f1d773b8c098aa6290b06f92`. 학습 시간 약 31ms(이번 실행의 단일 측정, 환경 의존). 전체 혼동행렬·클래스별 precision/recall·오류 ID·지연 p50/p95는 README 명령으로 `artifacts/`에 재생성할 수 있다.

단일 작성자의 합성 문장이고 독립 라벨 검토가 없으며, 평가 문구를 구현자가 작성했다. 보류는 분할 고정 회귀 실험이지 외부 블라인드 시험이 아니다. 같은 행위와 유사 표현이 학습·평가에 등장한다. 모든 사례가 단일 메시지여서 다화자 의미 분석은 별도 검증이 필요하다. 실제 피해 탐지율·서비스 정확도 주장에 쓰지 않는다.

기술 검증: 백엔드 54개, 프런트엔드 단위 6개 테스트 및 프런트엔드 빌드 통과. 백엔드는 스키마·인용·출처·API 오류·입력 보호·평가 오류 보존·설명 실패 시 핵심 결과 유지·성공 API 계약을 검사했고 자동 테스트의 LLM은 대역을 사용했다. API 키 미설정 시 평가 스크립트가 호출 없이 종료하는 것을 확인했다.

추가로 실제 Gemini 집중 회귀 14건을 실행했다. 최초 상태 일치 11/14, 실행 오류 2/14, 맥락 부족 과대 분류 1건을 확인했다. 수정 후 선택 8건 상태 분류가 통과했고, 설명 단정 표현을 추가 수정해 공격 문구 1건을 재검사했다. 정식 개발·보류 비교와 구분하며 [분석 품질 검토](llm-quality-review.md)에 상세 결과와 한계를 기록했다.

실제 연결 확인: Gemini `gemini-3.1-flash-lite`로 가상 인증정보 요구 1건을 전송해 `suspicious_signals` / `CREDENTIAL_REQUEST`, JSON 및 인용 검증을 통과했다. 성공 요청 1회·약 1.8초·입력 702/출력 333토큰. 이는 연결 확인이며 정식 60건 품질 평가 결과가 아니다. 원래 중첩 배열 상한이 있는 스키마는 HTTP 400을 반환했고, 생성 스키마의 길이·개수 제약을 단순화한 뒤 성공했다. 서버 제약 검증은 유지했다. 도중 모델 혼잡 503도 관찰했다.

공식 출처를 포함한 실제 검사 7건에서 상태가 모두 일치했다. 출처 기관명 추측과 자료 범위 확대를 수정한 뒤 4건을 재검사했다. 세 사례는 관련 공식 자료에 연결됐고 일반 환급 APK 사례는 관련 없는 자료를 제외했다. [근거·출처 검증 기록](source-review.md)에 한계와 상세 결과를 남겼다.

브라우저 핵심 흐름은 데스크톱·모바일 크기 12건과 실제 Gemini 화면 분석 1건을 통과했다. 테스트 응답 검사와 실제 호출을 구분해 [화면 점검 기록](browser-review.md)에 정리했다. 이는 UI 연결 확인이며 전체 분류 성능 평가를 대신하지 않는다.
