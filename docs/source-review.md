# 원문 근거·출처 검증 — 2026-11-09

오늘 저녁 시연의 핵심은 가상 문자·대화 입력부터 분류, 원문 인용과 이유 표시까지다. 공식 출처는 검증된 자료와 충분히 관련 있을 때 연결하며, 자료 부족이나 생성 실패로 핵심 분석을 잃지 않도록 한다.

## 실제 Gemini 검사

대출 선납, 인증정보 요구, 외부 APK, 확정 수익 보장, 다화자 출금 전 추가 납부, 예방 문구, 목적 없는 보증금 요청 7건을 검색·설명까지 포함해 실행했다. 상태는 기대와 7/7 일치했고 원문 인용·메시지 ID 검증을 통과했다. 모델 혼잡·타임아웃 오류는 이 실행에서 없었다.

초기 결과는 `artifacts/llm-rag-regression-initial.json`에 보존했다. 초기 연결 중 두 의미 문제를 발견했다.

- 출처 설명에 공식 기관명·제목이 전달되지 않아 금융위원회 자료를 금융감독원 자료라고 설명했다. 검색 조각에 검토된 publisher·title을 추가하고 기관명을 추측하지 않도록 수정했다.
- 주식 리딩방의 거래 앱 경고를 일반 환급 APK 설치 요구의 근거로 넓게 적용했다. 해당 조각은 실제 원문 인용에 주식·리딩방·투자 맥락이 있을 때만 검색되도록 제한했다. LLM이 만든 이유에 투자라는 단어가 있어도 원문에 없으면 검색에 쓰지 않는다.

출금 전 추가 납부 사례는 검색 유사도 기준을 넘는 조각을 찾지 못했다. 분류·운영자 m2 원문 인용은 유지하고 공식 근거 연결 부족을 표시했다. 예방·판단 곤란 사례에는 관련 없는 공식 자료를 붙이지 않았다.

## 수정 후 확인

대출·인증정보·외부 APK·수익 보장 4건을 다시 실행했다. 상태는 4/4 일치했고 실행 오류는 없었다. 대출은 금융위원회 FSC-001, 인증정보는 KISA-002, 수익 보장은 금융위원회·정책브리핑 FSC-002에 연결됐으며 설명의 기관명과 자료 범위를 검토했다. 일반 환급 APK는 관련 없는 주식 리딩방 자료가 제외되어 공식 출처 없이 원문 근거와 이유만 반환했다.

이번 4건은 p50 약 14.9초 / p95 약 29.3초였다. 단일 표본 묶음의 측정으로 지연 보장은 아니다. 최종 자료·프롬프트로 7건 전체를 재평가한 것은 아니다. 초기 결과와 수정 후 결과를 합쳐 성능을 주장하지 않는다.

수정 후 결과는 `artifacts/llm-rag-regression-source-fix.json`에 보존했다. 프롬프트 SHA256은 `6c6006f7fef5c565c527cb7b3fe1086fe5d9adfd4ca83ab22c791ae7493e32bb`, 자료 SHA256은 `cddb38ccea98a68db1e358b2a870e3b04a2dd94b3a9d1216d2bdf6ac9b23b262`다. 평가 스크립트도 이후 실행부터 자료 해시를 기록하고 재개 시 변경 여부를 확인한다.

## 오류와 검증

공식 설명은 남은 요청 시간과 설명 제한시간 중 짧은 범위에서 생성한다. 설명 타임아웃·모델 혼잡·무료 한도 오류·검색 실패·검증 실패에서는 검증된 분류와 원문을 유지하고 출처를 생략한다. 모든 출처 메타데이터를 검증한 뒤 링크를 부착하므로 도중 실패로 일부 신호에만 잘못된 링크가 남지 않는다.

자동 테스트에서 다음을 확인했다.

- 인용의 정확한 부분 문자열과 이모지·반복 발생 위치, 존재하는 메시지 ID·순서 검증.
- 검색에 반환되지 않은 출처·조각 조합의 거절과 서버에서 관리하는 URL 사용.
- 설명 시간 초과·503·429·504 및 출처 메타데이터 오류 시 핵심 결과 보존.
- 금융 앱 관련 자료의 원문 문맥 제한과 기관 메타데이터 전달.
- 분석 API의 성공 응답 계약·요청 ID·원문 위치와 없는 인용의 502 오류 응답.

백엔드 54개 테스트가 통과했다. 자동 모델 테스트는 대역이며 실제 호출 결과와 구분한다. 인용이 존재하고 출처 ID가 유효해도 해석의 정확성을 완전히 보장하지는 않는다. 후속 브라우저 핵심 흐름은 [화면 점검 기록](browser-review.md)에서 확인했고, 전체 개발·보류 비교는 남아 있다.
